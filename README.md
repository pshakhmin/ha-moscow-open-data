# Moscow Open Data

Интеграция для Home Assistant, которая использует API открытых данных Москвы для предоставления полезных сенсоров.

## Установка

1. Установите HACS (если ещё не установлен)
2. Добавьте этот репозиторий как локальный репозиторий в HACS
3. Установите интеграцию **Moscow Open Data** через HACS
4. Перезапустите Home Assistant

## Настройка

После установки перейдите в **Настройки → Устройства и службы → Добавить интеграцию** и введите свой адрес (улица, дом) и API-ключ.

**API-ключ обязателен.** Получить его можно в личном кабинете на [data.mos.ru](https://data.mos.ru/) в разделе для разработчиков. Без ключа API возвращает ошибку авторизации.

### Примеры адреса:
- `Москва, улица Ленина, дом 1`
- `ул. Тверская, д. 10`
- `улица Арбат, дом 5`

Сопоставление адреса частичное и нормализованное: интеграция разбирает введённую строку на токены, отбрасывает служебные слова (`ул`, `улица`, `дом`, `д` и т. п.) и ищет по названию улицы и номеру дома. Лучше всего указывать «улицу + дом» (например, `Тверская улица, дом 10`); свободный формат вроде `ул. Тверская, д. 10` тоже разбирается и нормализуется. Сопоставление **нечувствительно к регистру**: `тверская` и `Тверская` находят один и тот же дом.

## Предоставляемые сенсоры

### Бинарные сенсоры

| Сенсор | Описание |
|--------|----------|
| **Отопительный сезон активен** | Показывает, идёт ли сейчас отопительный сезон по официально объявленным датам |
| **Горячая вода отключена** | Показывает, ведётся ли сейчас отключение горячей воды по вашему адресу |

### Датчики

| Сенсор | Описание |
|--------|----------|
| **Следующее отключение горячей воды** | Дата следующего планового отключения горячей воды |
| **Восстановление горячей воды** | Дата восстановления подачи горячей воды после отключения |
| **Начало отопительного сезона** | Дата начала текущего сезона из официального анонса (МОЭК); «Неизвестно», пока сезон не объявлен |
| **Окончание отопительного сезона** | Дата окончания сезона из официального анонса (МОЭК); «Неизвестно», пока не объявлена |

## Источник данных

Данные о горячей воде получены из портала [Открытые данные Москвы](https://data.mos.ru/) (набор данных 1401 «График отключения горячей воды»).

Даты отопительного сезона определяются по официальным анонсам из RSS-лент [МОЭК](https://www.moek.ru/rss/) (основная) и [mos.ru](https://www.mos.ru/rss/) (резервная). Готового API с этими датами нет, поэтому найденные даты сохраняются в Home Assistant и держатся между объявлениями. Пока сезон не объявлен, соответствующие датчики показывают «Неизвестно».
